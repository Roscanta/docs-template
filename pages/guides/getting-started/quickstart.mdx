# Quickstart

Make your first JSON-RPC request to dRPC.

<Tabs items={["curl", "JavaScript", "Python"]}>
  <Tab>
    ```bash
    curl -X POST -H 'Content-Type: application/json' \
      -d '{"method": "eth_blockNumber","params": [],"id": "1","jsonrpc": "2.0"}' \
      'https://lb.drpc.org/ogrpc?network=ethereum'
    ```
  </Tab>
  <Tab>
    ```js
    const axios = require('axios');
    const url = 'https://lb.drpc.org/ogrpc?network=ethereum&dkey=YOUR_DRPC_API_KEY';

    axios.post(url, { jsonrpc: '2.0', id: 1, method: 'eth_blockNumber', params: [] })
      .then(r => console.log(parseInt(r.data.result, 16)));
    ```
  </Tab>
  <Tab>
    ```python
    import requests

    url = "https://lb.drpc.org/ogrpc?network=ethereum&dkey=YOUR_DRPC_API_KEY"
    payload = {"jsonrpc": "2.0", "id": 1, "method": "eth_blockNumber", "params": []}
    print(requests.post(url, json=payload).json())
    ```
  </Tab>
</Tabs>
